# دليل رفع المتجر على GitHub وربطه بنجاح

## الخطوة الأولى: إنشاء مستودع على جيت هب (GitHub Repository)
1. ادخل إلى موقع [GitHub](https://github.com) وسجل دخولك.
2. اضغط على زر **New** لإنشاء مستودع جديد.
3. سمِّ المستودع (مثلاً: `my-store`).
4. اختر اجعله **Public** (عام) ثم اضغط **Create repository**.

## الخطوة الثانية: رفع ملف المتجر
1. قم بتسمية الملف الذي جهزناه باسم **`index.html`**.
2. داخل صفحة المستودع على GitHub، اضغط على **uploading an existing file**.
3. اسحب ملف `index.html` وأفلته في الصفحة، ثم اضغط **Commit changes**.

## الخطوة الثالثة: ربط المتجر للاستضافة الدائمة (Netlify / Vercel)
1. ادخل إلى موقع [Netlify](https://app.netlify.com) وسجل بحساب جيت هب.
2. اختر **Add new site** ثم **Import an existing project**.
3. اختر مستودعك واضغط **Deploy**. سيعطيك الموقع فوراً رابطاً دائماً لمتجرك!
